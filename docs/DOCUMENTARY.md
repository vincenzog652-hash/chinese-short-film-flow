# โหมดสารคดีและเรื่องจริง

ใช้คู่มือนี้เมื่อเนื้อหาอ้างถึงบุคคล เหตุการณ์ ประวัติศาสตร์ ข่าว หรือข้อเท็จจริงที่ผู้ชมอาจนำไปเชื่อ ไม่ใช้กติกาเรื่องแต่งแทนการตรวจแหล่งข้อมูล

## 1. ทำ Source ledger ก่อนเขียนบท

แยกข้อมูลเป็นสามระดับ:

- **ยืนยันแล้ว:** มีแหล่งข้อมูลที่ตรวจย้อนกลับได้และสอดคล้องกัน
- **ขัดแย้ง/เป็นคำบอกเล่า:** แหล่งข้อมูลให้รายละเอียดต่างกัน ต้องเขียนให้เห็นความไม่แน่นอน
- **ยังไม่ยืนยัน:** ใช้เป็นคำถามหรือประเด็นค้นต่อ ห้ามเขียนเป็นข้อเท็จจริง

หนึ่ง claim ควรมี URL หรือชื่อเอกสาร ผู้จัดทำ วันที่เข้าถึง ตำแหน่งหน้า/เวลาในคลิป และถ้อยคำที่อนุมัติ หลีกเลี่ยงการอ้างเว็บที่คัดลอกต่อกันหลายทอดเป็นหลักฐานหลายแหล่ง

## 2. แยกภาพออกจากหลักฐาน

กำหนดสถานะทุกช็อตเป็น `ARCHIVAL`, `LICENSED`, `ILLUSTRATION` หรือ `AI_REENACTMENT` ภาพจำลองต้องไม่มีรายละเอียดใหม่ที่บทหรือหลักฐานไม่ได้รองรับ และควรมีป้าย “ภาพจำลอง” เมื่อผู้ชมอาจเข้าใจว่าเป็นภาพเหตุการณ์จริง

อย่าใช้ใบหน้าบุคคลจริงแบบสมจริงเพื่อสร้างเหตุการณ์ที่ไม่มีหลักฐาน หลีกเลี่ยงโลโก้ เอกสาร หนังสือพิมพ์ หรือคำพูดบนภาพที่โมเดลสร้างขึ้นเอง ให้ใส่ข้อความและซับในขั้นตัดต่อ

## 3. เขียนบทแบบตรวจย้อนกลับได้

ผูกแต่ละย่อหน้าหรือประโยคสำคัญกับ Claim ID ใช้ภาษาตามระดับหลักฐาน เช่น “เอกสารระบุว่า”, “มีคำบอกเล่าสองแนวทาง” หรือ “ยังไม่พบหลักฐานยืนยัน” ไม่แต่งบทสนทนาของบุคคลจริง เว้นแต่ระบุชัดว่าเป็นการเรียบเรียงหรือมีคำพูดจากแหล่งอ้างอิงที่อนุญาต

เสียงบรรยายสามารถผลิตแยกจากวิดีโอได้ เก็บ `narration script`, ไฟล์เสียง, รุ่นเสียง และสถานะการตรวจออกเสียงไว้ใน production log อย่าบังคับ lip sync หากช็อตเป็นภาพประกอบที่ไม่มีผู้พูดหน้ากล้อง

## 4. QC ก่อนเผยแพร่

- [ ] Claim สำคัญทุกข้อมีแหล่งอ้างอิงหรือคำเตือนความไม่แน่นอน
- [ ] ไม่ตัดคำพูดหรือภาพออกจากบริบทจนความหมายเปลี่ยน
- [ ] สิทธิ์ใช้ภาพ คลิป เสียง และเพลงถูกบันทึก
- [ ] ภาพจำลอง AI มี disclosure เหมาะสม
- [ ] ซับตรงกับเสียงและสะกดชื่อบุคคล/สถานที่ถูกต้อง
- [ ] ผู้ตรวจแยก factual review ออกจาก visual/audio QC

หากยังตรวจข้อเท็จจริงไม่ครบ ให้ใช้ `FACT_CHECK_PENDING` และห้ามเลื่อนสถานะตอนเป็น `PUBLISHED`
